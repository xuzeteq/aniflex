# 🎌 aniflex — твой гид по миру аниме

**aniflex** — это современный веб-сайт для просмотра аниме, разработанный на C# + React с использованием  PostgreSQL в качестве базы данных. Проект создан для удобного поиска, просмотра и оценки любимых тайтлов.

---

## 🚀 Возможности aniflex

### 👤 Пользовательская часть
- 🔍 **Просмотр аниме** — каталог с удобной навигацией
- 📝 **Регистрация / авторизация** — через email и пароль
- 🔐 **Восстановление пароля** — через почту
- ✅ **Верификация аккаунта** — подтверждение email
- ❤️ **Система лайков и оценок** — оценивай аниме и ставь лайки
- 🧭 **Множество страниц**:
  - Каталог
  - Профиль пользователя
  - Страница отдельного аниме
  - Логи
  - Архив 2025 / 2026 годов

### 🛠️ Административная панель
- 🧾 **Логирование серверной части** — просмотр серверных логов
- 🧾 **Журнал аудита** — отслеживание действий пользователей
- 👥 **Управление пользователями** — роли, блокировки, верификация

### 🔎 Поиск
- Реализована **базовая система поиска аниме** по названию. Поиск поддерживает как русский, так и английский ввод.
